# P2 Route-Security Matrix

The canonical machine-readable inventory is `ProductionRouteSecurityPolicyCatalog`; `security:routes:verify` rejects
an unclassified route, a non-GET mutation without CSRF metadata, catalog drift, missing no-store metadata for
token-bearing routes, and a public administrative controller. `RouteCollection` separately rejects duplicate names and
ambiguous route precedence during construction. This matrix mirrors the 88 registered routes. Comma-separated names are
separately registered routes sharing the stated tuple.
