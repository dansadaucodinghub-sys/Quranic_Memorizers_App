This matrix provides one row for every requirement in [P0-B01 Requirements](P0-B01-requirements.md), connects it to its source, canonical concepts, primary actor, owning module, business invariant, planned specification point, and objective verification method, and records current delivery status.

## Scope and status convention

All rows are baselined documentation obligations. “P0-B02; delivery unassigned” means detailed functional specification is next while the implementation roadmap remains open under OD-030. It does not mark the requirement implemented or verified.
