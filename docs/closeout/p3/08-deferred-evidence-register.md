# P3 Deferred Evidence Register

The authoritative deferred-evidence matrix is maintained in [P3 deferred evidence register](../../security/P3-deferred-evidence-register.md). All items have an owner, target gate and compensating control. None is asserted as executed merely because P3 source verification passes.

| Class | Closeout treatment | P3 source-closeout blocker |
| --- | --- | --- |
| Hosted CI and independent penetration testing | external release evidence | No |
| Manual keyboard, screen-reader, zoom, forced-colour, mobile/browser testing | external accessibility evidence | No |
| Production key custody, proxy, provider and scheduler operations | production operations evidence | No |
| Legal terminology/minor-policy and external Geography review | governance evidence | No |
| Production-scale load and disaster-recovery rehearsal | operations evidence | No |
