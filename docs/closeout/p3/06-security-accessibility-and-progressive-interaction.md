# P3 Security, Accessibility and Progressive Interaction

`security:p3:verify` and `security:person-repositories:verify` provide bounded, read-only current evidence in addition to P2 authorization, tenant, privileged-access, audit and route verifiers. The private P3 interface uses no-store responses, CSRF/idempotency controls and server-rendered fallbacks. Automated translation, RTL, storage-boundary and interaction tests are executable; manual accessibility evidence remains deferred.
