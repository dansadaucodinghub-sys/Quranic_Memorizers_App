# P3 Accessibility and Progressive-Interaction Verification

P3 preserves the P1/P2 server-rendered fallback, translation, RTL, focus, semantic validation and progressive fragment controls. Private profile, affiliation, claim and duplicate flows are no-store and do not persist authority or sensitive data in browser storage.

Automated evidence is executable. Manual keyboard, screen-reader, zoom, forced-colour, mobile and physical-passkey evidence remains explicitly deferred and is not claimed as complete.
